Studio WR

Ferramenta pessoal de produção de vídeos para YouTube · Personal YouTube video production tool

O que é

O Studio WR é um aplicativo de uso pessoal, executado localmente no computador do próprio criador, para produzir vídeos dos seus canais no YouTube. Ele não é oferecido ao público nem vendido.

Como usa o YouTube

Com a autorização do dono do canal (login do Google / OAuth), o Studio WR usa a YouTube Data API apenas para:

  • listar os envios recentes do próprio canal, para encontrar o vídeo que o criador acabou de enviar;
  • preencher o título, a descrição, as tags, a declaração "não é conteúdo para crianças" e a visibilidade desse vídeo;
  • enviar a thumbnail escolhida pelo criador.

O Studio WR não envia, apaga nem publica vídeos por conta própria, e não acessa canais de outras pessoas.

About (English)

Studio WR is a personal, locally-run desktop tool used by its owner to prepare videos for their own YouTube channels. With the channel owner's consent it uses the YouTube Data API only to find the owner's recently uploaded video and set its title, description, tags, audience setting, privacy status and thumbnail.
