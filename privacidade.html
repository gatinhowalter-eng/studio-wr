Política de Privacidade

Última atualização: 8 de novembro de 2026

O Studio WR é um aplicativo de uso pessoal, executado localmente no computador do seu dono. Esta política explica quais dados ele acessa por meio das APIs do Google e o que faz com eles.

Dados acessados

Quando o dono de um canal autoriza o Studio WR com a sua conta Google, o aplicativo acessa, pela YouTube Data API:

  • informações básicas do canal autorizado (nome e identificador);
  • a lista de vídeos enviados recentemente a esse canal;
  • os metadados desses vídeos (título, descrição, tags, visibilidade, configuração de público e thumbnail).

Como os dados são usados

Esses dados são usados apenas para localizar o vídeo que o próprio dono do canal enviou e preencher o título, a descrição, as tags, a declaração "não é conteúdo para crianças", a visibilidade e a thumbnail desse vídeo. O Studio WR não envia, apaga nem publica vídeos sozinho.

Armazenamento e compartilhamento

  • Os tokens de acesso do Google ficam salvos somente no computador onde o Studio WR é executado. Não existe servidor externo do Studio WR.
  • Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.
  • O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Serviços do YouTube

O Studio WR usa os Serviços de API do YouTube. Ao autorizar o aplicativo, você também está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

Como revogar o acesso

Você pode desconectar o canal a qualquer momento no próprio Studio WR (Configurações → YouTube → Desconectar), o que apaga o token local, ou remover o acesso na página de permissões da sua Conta Google.

Privacy Policy (English)

Studio WR is a personal application that runs locally on its owner's computer. When a channel owner authorizes it with their Google account, it uses the YouTube Data API to read basic channel information, the channel's recent uploads and their metadata, solely to locate the owner's newly uploaded video and set its title, description, tags, audience setting, privacy status and thumbnail. It does not upload, delete or publish videos on its own.

Google access tokens are stored only on the computer running Studio WR; there is no Studio WR server. No data is sold, shared with third parties or used for advertising. Studio WR's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Studio WR uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

You can revoke access at any time in Studio WR (Settings → YouTube → Disconnect) or at Google Account permissions. Contact: gatinhowalter@gmail.com.
